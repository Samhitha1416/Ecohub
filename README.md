# Ecohub: E-Waste Monitoring System

# Overview

Ecohub is an intelligent web application designed to address the global challenge of electronic waste, with a strong focus on the Indian e-waste ecosystem. The platform provides organizations, authorized recycling facilities, and the Pollution Control Board (PCB) with tools to track electronic devices, manage inventory, analyze consumption data, and ensure responsible recycling.

This system also integrates PHPMailer, which is used to send real-time email notifications and live tracking updates to users regarding e-waste movement, status changes, and important alerts.

# Features
## User Accounts
### 1. Organizations

- View graphical dashboards

- Analyze electronic consumption patterns

- List and sell e-waste (quantity, type, weight)

- Manage inventory efficiently

### 2. Authorized Recycling Facilities

- Access recycling dashboards

- Maintain records of recycled e-waste

- Track incoming e-waste batches

### 3. Pollution Control Board (PCB)

- Monitor e-waste from collection to recycling

- Receive live updates

- Oversee compliance

### 4. Future User Accounts – Individuals

- Individuals will be able to sell and track their e-waste directly through the platform


## Dashboard & Analytics

- Real-time e-waste tracking

- Visual representations and graphs

- Statistical insights for decision-making

- Trend analysis and consumption patterns
